# Voting Systems Intro

This repository contains the `Voting_Systems_Intro.ipynb` notebook and the
local Python module, data files, and images it uses. Keep the notebook and the
`voting_functions.py`, `CVR files/`, and `SP images/` paths together as shown;
the notebook reads these files using relative paths.

## To run the notebook locally

1. Install Python 3.11 through 3.13 and JupyterLab.
2. From this repository folder, install the dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start JupyterLab from this folder:

   ```bash
   jupyter lab
   ```

4. Open `Voting_Systems_Intro.ipynb` and read the instructions provided in the notebook.

The notebook hides and locks code cells in compatible Jupyter interfaces.
This is only a display/editing convenience; the notebook source is still
available to anyone who downloads the file.

## To run the notebook in the cloud on JupyterHub.

1. Open this [Binder link](https://mybinder.org/v2/gh/gmorre/Voting-Systems-Intro/HEAD?urlpath=%2Fdoc%2Ftree%2FVoting_Systems_Intro.ipynb)
2. Wait, it will take a few minutes for the file to open in Jupyter notebook to open in your browser.
3. Read the instructions provided in the notebook.

When running the notebook this way your session will timeout after 10 minutes of inactivity. If you are not ready to move on to the next cell, you can re-run an old cell to keep the session active.
